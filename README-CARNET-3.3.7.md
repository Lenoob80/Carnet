# Carnet 3.3.7 — navigation personnalisable

## Nouveauté
- Dans **Paramètres → Navigation supérieure**, chaque rubrique du bandeau supérieur peut être affichée ou masquée individuellement.
- Le bouton **Tout afficher** restaure toutes les rubriques.
- Paramètres reste toujours accessible pour pouvoir réactiver une rubrique masquée.
- Les préférences sont enregistrées sur l'appareil et conservées après actualisation.
- Masquer une rubrique ne supprime aucune page, note ou donnée.

## Compatibilité
Cette version reprend Carnet 3.3.6 et conserve le carnet existant, les pages, les notes, la connexion ENT HDF, Pawnote et le relais Pronote. Aucune migration ni remise à zéro des données n'est effectuée.

## Installation
Remplacer les fichiers du dossier `Carnet` par ceux de cette archive, publier le site puis actualiser complètement la page. Ne pas effacer les données du navigateur ni le dépôt de sauvegarde.

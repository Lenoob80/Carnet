# Carnet 3.3.6 — correctif de disposition et démarrage

## Correctifs
- Restaure un véritable panneau latéral vertical sur ordinateur : sélecteur compact, sections et pages dans leurs propres zones de défilement.
- Sur mobile, transforme les sections et les pages en deux bandes horizontales compactes ; le sélecteur ne peut plus s'étirer en grand carré.
- L'éditeur garde une grande toile libre sur ordinateur et repasse en une seule colonne sur mobile.
- À chaque nouveau chargement du site, l'application ouvre l'Accueil après le chargement des données, sans modifier ni réinitialiser les carnets enregistrés.
- Incrémente le cache hors ligne pour forcer le chargement de cette version.

## Installation
Remplacer le contenu du dossier `Carnet` par celui de cette archive. Ne pas supprimer les données du navigateur, le dépôt de sauvegarde ni le relais Pronote. Après publication, faire `Ctrl + F5` sur ordinateur ou fermer/réouvrir l'onglet sur mobile.

Les changements ne migrent ni ne réinitialisent les données personnelles.

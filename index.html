📓 Mon carnet

Tes notes sont chiffrées sur cet appareil avant d’être envoyées sur ton dépôt GitHub privé.

❓ Comment obtenir le dépôt et le jeton ?
  1. Sur github.com, crée un dépôt privé vide (ex. carnet-data).
  2. Va dans Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access : « Only select repositories » → ton dépôt privé. Permissions → Contents : Read and write.
  4. Copie le jeton (il ne s’affiche qu’une fois) et colle-le ci-dessous. Dépôt = pseudo/carnet-data. Note aussi sa date d’expiration.
  5. L’e-mail et le mot de passe choisis ici chiffrent tes notes : ils ne sont pas récupérables, garde-les.

Pré-créer des pages hebdomadaires

Les matières sont copiées depuis la page ouverte (ou le modèle par défaut).

Si rempli, remplace début / fin / pas. « 42-44 » = de 42 à 44 (42-43-44). Les numéros qui repartent à 1 passent à l’année suivante.

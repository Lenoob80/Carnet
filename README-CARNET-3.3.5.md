# Carnet 3.3.5 — espace de travail adaptatif

## Changements
- Le panneau des sections/pages reste sur toute la hauteur disponible sur ordinateur.
- La navigation des sections et des pages reste dans le panneau latéral, avec ses propres défilements.
- L'espace d'édition devient une grande toile de travail (3200 × 2200 px minimum) avec défilement horizontal et vertical, sans feuille blanche étroite.
- Les blocs gardent leur position absolue sur ordinateur afin de permettre une disposition libre de type OneNote.
- Le ruban reste compact et défilable sans recouvrir le contenu.
- Sur mobile, les sections et pages deviennent deux bandes horizontales et le contenu se réorganise en une seule colonne pour rester lisible et utilisable au toucher.
- Le mode Concentration masque uniquement la navigation globale, pas les pages du carnet.
- Version du cache hors ligne augmentée pour forcer le rechargement des fichiers.

## Installation
Remplacer les fichiers du dossier `Carnet` par ceux de cette archive à l'emplacement du site. Garder le relais Pronote et le dossier de construction Pawnote séparés, comme auparavant. Ne pas effacer les données du navigateur.

Cette version ne migre ni ne réinitialise les données personnelles. Les changements sont principalement CSS et n'altèrent pas les coordonnées enregistrées des blocs.
